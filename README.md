# NeetCode 150

A structured collection of solutions to the **NeetCode 150** roadmap, implemented in **Java**.

This repository documents my journey of strengthening Data Structures and Algorithms fundamentals, developing pattern-based problem-solving skills, and preparing for technical interviews and coding assessments.

## About

The NeetCode 150 roadmap covers essential Data Structures and Algorithms concepts commonly used in technical interviews.

Each solution in this repository is organized by topic and focuses on understanding the underlying approach rather than simply solving individual problems.

## Topics Covered

- Arrays & Hashing
- Two Pointers
- Sliding Window
- Stack
- Binary Search
- Linked List
- Trees
- Tries
- Heap / Priority Queue
- Backtracking
- Graphs
- Advanced Graphs
- 1-D Dynamic Programming
- 2-D Dynamic Programming
- Greedy
- Intervals
- Math & Geometry
- Bit Manipulation

## Solution Format

Each problem is organized with:

- Problem name and platform reference
- Problem-solving approach
- Java implementation
- Time complexity
- Space complexity
- Key concepts and patterns

This structure makes the repository useful for both learning and future revision.

## Approach

My approach to each problem is:

1. Understand the problem and constraints.
2. Identify the underlying DSA pattern.
3. Develop and test a solution.
4. Analyze time and space complexity.
5. Optimize where necessary.
6. Document the key idea for future reference.
